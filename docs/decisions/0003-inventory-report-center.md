# 0003 進銷存系統新增獨立報表中心

## 背景

進銷存系統的報表會逐步增加。如果所有報表都塞在庫存頁，後續會讓導覽和畫面結構變混亂。

## 決定

新增獨立「報表中心」頁籤，集中放置銷售摘要、進貨摘要、毛利排行與庫存報表。

## 理由

- 後續新增報表時有固定入口。
- 庫存報表仍可保留，但不再佔用主導覽中的單一功能位。
- 報表中心能共享月份篩選與摘要卡片。

## 版本

`v1.14.0`

## 後續擴充

`v1.6.0` 已在報表中心加入庫存異動明細，`v1.9.0` 已接入盤點調整，`v1.13.0` 已讓異動明細帶出倉庫資訊，`v1.14.0` 已加入倉庫庫存摘要與商品跨倉分布。後續退貨、調撥等異動也應優先接入同一個明細報表。
