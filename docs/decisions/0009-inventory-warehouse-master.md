# 0009 新增倉庫基本資料

## 背景

StockFlow 要從單倉進銷存走向多倉庫，不能直接先改庫存計算。倉庫必須先成為穩定主檔，後續進貨、銷售、盤點和報表才能逐步接上倉庫維度。

## 決定

在基本資料中心新增倉庫主檔，欄位包含倉庫代碼、名稱、類型、備註與啟用狀態。`v1.12.0` 只建立主檔，不改進貨、銷售、盤點和庫存報表的計算方式。`v1.13.0` 已把採購、銷售、盤點接上倉庫，庫存改以商品 + 倉庫維度計算。

舊資料若沒有倉庫資料，載入時自動建立預設主倉。

## 理由

- 先建立主檔可降低多倉導入風險。
- 備份還原可以先納入倉庫資料。
- 後續 `v1.14.0` 再強化倉庫別庫存報表與篩選。

## 版本

`v1.12.0`
