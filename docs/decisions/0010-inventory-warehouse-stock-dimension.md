# 0010 庫存計算加入商品與倉庫維度

## 背景

StockFlow 已在 `v1.12.0` 建立倉庫主檔。下一步需要讓真實交易指定倉庫，否則倉庫只會停留在基本資料，庫存仍然無法回答「這個商品在哪個倉庫有幾個」。

## 決策

`v1.13.0` 起，採購、銷售與盤點調整都必須帶有 `warehouseId`。庫存計算改為同商品、同倉庫分開累計：

```text
目前庫存 = 同商品同倉庫進貨 + 同商品同倉庫調整 - 同商品同倉庫銷售
```

舊資料若缺少 `warehouseId`，載入時一律補到預設主倉，避免升級後歷史資料失效。

## 影響

- 同商品在主倉、門市或其他倉庫可以有不同庫存數。
- 銷售庫存不足檢查只檢查指定出貨倉庫。
- 盤點調整只校正指定倉庫。
- 庫存報表改列出商品 + 倉庫資料列。
- 後續 `v1.14.0` 可在此基礎上加入倉庫報表篩選、彙總與更清楚的倉庫別視圖。

## 版本

`v1.13.0`
