# 0008 新增基本資料中心與備份還原

## 背景

進銷存系統的交易資料會圍繞基本資料運作。若產品類別、倉庫、單位、往來對象等資料沒有穩定管理，後續報表、篩選、備份和多倉庫都會變得脆弱。

## 決定

先新增「基本資料中心」，第一階段放入產品類別主檔與資料管理。產品類別從商品上的文字欄位升級為主檔資料，但保留舊商品分類相容性。

資料管理先支援：

- 匯出完整 JSON 備份。
- 選擇備份檔後先檢查與預覽。
- 確認後整包還原。

## 理由

- 類別主檔是後續商品分析、報表分組與權限控管的基礎。
- 備份還原必須在多倉庫、更多主檔之前先穩住。
- 先做整包還原，避開合併還原的 ID、SKU 和單號衝突問題。
