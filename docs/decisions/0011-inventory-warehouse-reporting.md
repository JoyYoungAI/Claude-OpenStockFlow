# 0011 強化倉庫庫存報表

## 背景

`v1.13.0` 已讓採購、銷售與盤點指定倉庫，庫存也改成商品 + 倉庫維度。接下來若立刻進入調撥單，使用者仍缺少一個清楚視角來確認各倉庫的庫存狀態。

## 決策

`v1.14.0` 先強化報表中心與庫存報表：

- 庫存報表加入倉庫篩選。
- 報表中心新增倉庫庫存摘要。
- 報表中心新增商品跨倉分布。
- CSV 匯出依目前庫存報表篩選條件輸出。

## 影響

- 使用者可以先確認各倉庫庫存值、低庫存數與庫存分布。
- 後續做倉庫調撥時，有足夠報表可以驗證調撥前後的結果。
- 這一版不新增新的資料格式，`dataSchemaVersion` 維持 `5`。

## 版本

`v1.14.0`
