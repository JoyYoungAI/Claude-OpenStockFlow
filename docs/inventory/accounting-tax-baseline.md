# 發票、稅務、會計分錄基準線

本基準線定義 StockFlow 在發票、稅務與會計分錄上的邊界。系統目前先做營運財務，不假裝是完整會計總帳；但資料要保留未來銜接發票、稅務申報與會計分錄的空間。

## 核心原則

- 營運財務與會計財務要分清楚。
- 應收應付不等於正式會計分錄。
- 發票與稅務資料需可關聯原單，但不可破壞原進銷存流程。
- 會計分錄需有借貸平衡、科目、期間與鎖帳概念；未完成前不得標示為正式帳務。
- 稅務規則會依地區變動，第一階段只保留欄位與匯出邊界。

## 邊界

第一階段做：

- 營運收入、成本、毛利。
- 應收、應付、收款、付款。
- 發票號碼欄位預留。
- 稅額欄位預留。
- 會計匯出格式規劃。

第一階段不做：

- 正式總帳。
- 借貸分錄自動過帳。
- 稅務申報。
- 電子發票串接。
- 銀行對帳。
- 月結鎖帳。

## 發票資料

| 欄位 | 說明 |
|---|---|
| `invoiceNo` | 發票號碼。 |
| `invoiceDate` | 發票日期。 |
| `taxType` | 稅別。 |
| `taxRate` | 稅率。 |
| `taxAmount` | 稅額。 |
| `invoiceStatus` | 未開、已開、作廢、折讓。 |
| `sourceDocumentNo` | 來源單據。 |

## 會計分錄草案

未來會計分錄至少包含：

| 欄位 | 說明 |
|---|---|
| `journalNo` | 分錄編號。 |
| `date` | 分錄日期。 |
| `accountCode` | 科目代碼。 |
| `debit` | 借方金額。 |
| `credit` | 貸方金額。 |
| `sourceDocumentNo` | 來源單據。 |
| `lockedPeriod` | 是否屬於已鎖帳期間。 |

所有分錄必須借貸平衡；若不平衡，不可入帳。

## 稅務與折讓

- 銷售退貨可能產生折讓或發票作廢。
- 進貨退貨可能影響進項稅額。
- 作廢單據需判斷是否已開立發票。
- 已開立發票的作廢，不得只改進銷存單據，需建立稅務待辦。

## 與其他基準線的關係

- 退貨流程需提供折讓與發票作廢入口。
- 作廢反向事件 UI 需顯示是否有發票或會計影響。
- 雲端同步導入後，發票與會計資料需服務端鎖定。
