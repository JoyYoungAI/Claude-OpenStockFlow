# 報表與空狀態規格

報表是使用者確認庫存、金額與流程結果的地方。報表文字、空狀態與匯出欄位必須穩定，避免同一份資料在不同畫面出現不同解讀。

## 庫存查看流程

1. 使用者進入庫存報表。
2. 系統以商品 + 倉庫列出目前庫存、成本、售價、安全庫存。
3. 同一商品在不同倉庫分開判斷低庫存。
4. 使用者可依分類、倉庫、低庫存狀態或關鍵字篩選。

## 報表範圍

- 商品庫存。
- 倉庫庫存摘要。
- 商品跨倉分布。
- 低庫存。
- 庫存價值。
- 銷售收入。
- 粗略毛利。
- 庫存異動明細。
- CSV 匯出。

## 文字規則

- 報表標題、欄位、摘要、空狀態文字由 `inventoryI18n.js` 管理。
- 空狀態不得只顯示空白表格，必須讓使用者知道目前沒有符合條件的資料。
- 匯出 CSV 欄位要與畫面篩選條件一致。

## 驗證

- 庫存報表計算。
- 低庫存判斷。
- 倉庫庫存摘要。
- 商品跨倉分布。
- 倉庫篩選。
- CSV 資料輸出。
