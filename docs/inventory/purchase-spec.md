# 採購進貨規格

採購進貨負責把外部採購結果轉成指定倉庫的可用庫存。若商品暫時沒有庫存，但可以跟原廠或供應商進貨，這個流程就是出貨前的補貨來源。

## 流程

1. 使用者選擇商品。
2. 選擇入庫倉庫。
3. 填入進貨數量、進貨單價、供應商、日期、備註。
4. 系統建立進貨紀錄。
5. 系統增加該商品在指定倉庫的庫存。
6. 系統更新商品平均成本或最近進貨成本。

## Purchase

| 欄位 | 型別 | 必填 | 說明 |
|---|---|---:|---|
| id | number | 是 | 進貨紀錄 ID |
| productId | number | 是 | 商品 ID |
| warehouseId | number | 是 | 入庫倉庫 ID |
| quantity | number | 是 | 進貨數量 |
| unitCost | number | 是 | 進貨單價 |
| supplier | string | 否 | 供應商 |
| date | string | 是 | 日期，格式 `YYYY-MM-DD` |
| note | string | 否 | 備註 |
| ownerEmployeeId | number | 否 | 進貨單主要負責人，若尚未指定可留空。 |
| ownerDepartmentId | number | 否 | 進貨單負責部門，若尚未指定可留空。 |
| createdByEmployeeId | number | 否 | 建立進貨單的人員 ID，保留給人員權限與稽核使用。 |
| lastEditedByEmployeeId | number | 否 | 最近修改進貨單的人員 ID，保留給後續修改流程使用。 |

## 資料規則

- 進貨數量必須大於 0。
- 進貨必須指定有效且啟用的商品。
- 進貨必須指定有效且啟用的倉庫。
- 停用商品不可新增進貨，但仍可出現在歷史紀錄和報表中。
- 若目前已選擇本機人員，新增進貨單時需帶入負責人與負責部門，供主管範圍與稽核判斷使用。

## 驗證

- 進貨新增成功。
- 進貨增加指定倉庫庫存。
- 進貨紀錄可依月份或關鍵字篩選。
- 進貨資料出現在庫存異動明細。
