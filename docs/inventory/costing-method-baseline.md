# 成本法基準線

本基準線定義 StockFlow 的成本計算策略。第一階段維持簡化成本，正式營運版需預留 FIFO 與移動加權的資料結構，避免後續導入時無法追溯歷史庫存成本。

## 核心原則

- 成本法會影響毛利、庫存價值、退貨、作廢、報表與會計分錄。
- 成本計算不可只依商品目前成本覆蓋歷史。
- 每次進貨應形成成本層或成本事件。
- 銷售出貨應記錄當下採用的成本依據。
- 成本法切換需要管理生效日，不可直接重算全部歷史而不留痕跡。

## 成本法

| 成本法 | 系統值 | 說明 |
|---|---|---|
| 簡化目前成本 | `standardCost` | 使用商品目前成本估算庫存與毛利，適合第一階段。 |
| 移動加權 | `movingAverage` | 每次進貨後重算平均成本，適合一般買賣業。 |
| 先進先出 | `fifo` | 依進貨批次順序出貨，適合成本波動或需批次追蹤的商品。 |

## 第一階段決策

第一階段維持 `standardCost`，但新增規格與欄位預留：

- 商品可保留 `costingMethod`。
- 進貨保留 `costLayerId` 或批次識別。
- 銷售保留 `costBasis`。
- 報表保留「估算毛利」與「正式成本毛利」的區別。

## 成本事件

正式成本法需能記錄：

| 事件 | 說明 |
|---|---|
| 進貨入庫 | 建立成本層。 |
| 銷售出庫 | 消耗成本層或平均成本。 |
| 銷售退貨 | 依原銷售成本回補或進入待驗。 |
| 進貨退貨 | 移除或調整成本層。 |
| 盤點調整 | 依調整原因認列成本差異。 |
| 作廢 / 沖銷 | 建立反向成本事件，不直接改寫歷史。 |

## FIFO 規則

- 進貨建立批次成本層。
- 銷售依最早可用成本層扣減。
- 銷售退貨優先關聯原銷售成本。
- 作廢銷售回補原成本層。
- 成本層需保留 `sourceDocumentNo`、數量、單位成本、剩餘數量。

## 移動加權規則

```text
新平均成本 = (原庫存數量 * 原平均成本 + 本次進貨數量 * 本次進貨單價) / 新庫存數量
```

- 銷售使用當下平均成本。
- 進貨退貨與作廢需建立反向成本事件。
- 負庫存時不得自動重算平均成本，需先處理庫存例外。

## 報表

- 庫存報表需標示成本法。
- 毛利報表需標示是否為估算。
- 成本法切換前後需可追溯。
- CSV 匯出需包含成本法與成本依據欄位。
