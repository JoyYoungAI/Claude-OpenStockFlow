# 即時同步教學專區規格

即時同步教學專區是一個獨立模組，入口預計放在系統右上角。它不是一般說明頁，而是讓新人能依章節學會「瀏覽器本機資料、即時同步提示、多視窗風險、備份還原、單據關聯」的操作學習區。

本模組資訊架構參考 W3Schools 的教學模式：上方主分類、搜尋、左側章節、主內容、範例、練習、參考資料與前後章節導覽。參考的是教學骨架，不複製其品牌、文案或視覺。

## 目標

- 讓新同仁能在不打斷作業流程的情況下，自助理解系統同步與資料安全。
- 讓使用者知道「瀏覽器版本」與「即時同步」的限制、風險與正確行為。
- 把危險操作教學前置，降低誤出貨、誤還原、舊資料覆寫與帳款錯誤。
- 為後續多人協作、後端同步或雲端版本保留教學架構。

## 模組定位

| 項目 | 定義 |
|---|---|
| UI 入口 | 右上角教學入口，建議文字為 `教學` 或 `同步教學` |
| data-tab | `learning` |
| 狀態 | 獨立教學模組，不編入進銷存主流程步驟 |
| 對象 | 新人、倉庫人員、業務、財務、管理者 |
| 主要內容 | 即時同步、資料安全、多視窗、備份還原、單據關聯、人肉驗證流程 |

## 參考架構

W3Schools 首頁有 `Tutorials`、`References`、`Exercises`、`Certificates` 等主分類與搜尋入口；服務區也列出 Tutorials、References、Exercises、Quizzes、Code Editor 等學習構件。教學頁則有左側章節清單、前後章節導覽、Exercises、Code Challenge 與 Reference 入口。

本模組採用下列對應：

| W3Schools 類型 | StockFlow 對應 |
|---|---|
| Tutorials | 教學章節 |
| References | 名詞與規則參考 |
| Exercises | 操作練習 |
| Quizzes | 情境判斷題 |
| Try it Yourself / Code Editor | 沙盒示範或範例資料演練 |
| 左側章節 | 同步教學目錄 |
| Previous / Next | 上一章 / 下一章 |

## 頁面骨架

```text
右上角入口：同步教學
  -> 教學首頁
      -> 左側章節目錄
      -> 主內容區
      -> 本章重點
      -> 操作示範
      -> 情境練習
      -> 參考規則
      -> 上一章 / 下一章
```

桌面版：

- 左側固定章節目錄。
- 中央主內容。
- 右側可選章節重點或名詞索引。

手機版：

- 章節目錄收合為頂部選單。
- 主內容單欄。
- 上一章 / 下一章固定在章節底部。

## 第一版章節

| 章節 | 目的 | 必含內容 |
|---|---|---|
| 0. 快速開始 | 讓新人知道先看哪裡 | 系統目前是瀏覽器版本、資料存在本機、先匯出備份 |
| 1. 什麼是同步狀態 | 解釋即時同步與目前本機版本差異 | 本機資料、其他視窗更新、重新整理 |
| 2. 多視窗風險 | 防止舊資料覆寫 | 多分頁、無痕視窗、同事共用電腦 |
| 3. 舊資料警示 | 教使用者看到警示時怎麼做 | 暫停新增、先重新整理、確認單據 |
| 4. 備份與還原 | 防止還原錯資料 | 匯出、預覽、還原、重設範例資料 |
| 5. 單據編號關聯 | 教使用者追單據影響 | `PO`、`SO`、`LOAN`、`LRTN`、應收應付 |
| 6. 借出與歸還 | 教倉庫與業務共同流程 | 借出中、轉出貨、待驗區、倉庫確認 |
| 7. 財務與獎金風險 | 教出貨後的應收與獎金狀態 | `held`、`eligible`、未收款保留 |
| 8. 人肉驗證清單 | 給同事驗證用 | 範例資料、報表查詢、財務查詢、庫存查詢 |

## 內容資料模型

教學內容應以資料驅動畫面，避免把章節寫死在 HTML。

### LearningTopic

| 欄位 | 型別 | 說明 |
|---|---|---|
| id | string | 穩定章節 ID |
| title | string | 章節標題 |
| category | string | `tutorial`、`reference`、`exercise`、`quiz` |
| sortOrder | number | 顯示排序 |
| summary | string | 章節摘要 |
| sections | array | 內容區塊 |
| relatedSpecLinks | array | 關聯規格 |
| relatedFeatureIds | array | 關聯 UI 或功能 |
| nextTopicId | string | 下一章 |
| previousTopicId | string | 上一章 |

### LearningSection

| 欄位 | 型別 | 說明 |
|---|---|---|
| type | string | `text`、`steps`、`example`、`warning`、`checklist`、`quiz` |
| heading | string | 區塊標題 |
| body | string | 內容 |
| items | array | 步驟、清單或選項 |
| riskLevel | string | `info`、`warning`、`danger` |

### LearningProgress

| 欄位 | 型別 | 說明 |
|---|---|---|
| topicId | string | 章節 ID |
| status | string | `notStarted`、`reading`、`completed` |
| completedAt | string | 完成時間 |
| quizScore | number | 測驗結果 |

第一版可先只存在 `localStorage`，未來同步版本再移到使用者帳號或後端。

## 操作練習

第一版練習不直接修改正式資料，採用「指引式驗證」：

- 引導使用者按「重設範例資料」。
- 前往 `E1 調撥` 搜尋 `LOAN` 與 `LRTN`。
- 前往 `E2 財務` 搜尋 `SO`、`PO`。
- 前往 `6 庫存報表` 篩選 `INSPECT` 待驗區。
- 回答情境題：「借出歸還後，是否能直接回可售庫存？」

後續可加入沙盒模式，讓練習資料與正式資料完全隔離。

## 文字與語系

- 教學模組所有可見文字必須納入 `inventoryI18n.js` 或未來獨立 `inventoryLearningContent.js`。
- 教學內容可比作業畫面更白話，但警示文字必須精準。
- 危險情境不可只寫「請注意」，要說明錯誤後果。

## 視覺與 UI 狀態

- 右上角入口屬次要入口，不可比出貨、匯出、重設等操作更強。
- 教學入口可使用白底或淡色，hover/focus 需清楚。
- 章節完成狀態可用文字與圖示雙重提示，不只靠顏色。
- 危險警示使用與操作狀態基準線一致的紅色語意。
- 教學頁不可遮住目前工作資料；若採用抽屜或彈窗，必須能明確關閉。

## 即時同步教學重點

本模組需教會使用者：

- 目前本機版資料儲存在瀏覽器。
- 多個視窗同時操作可能造成舊資料。
- 看到舊資料警示時，寫入操作會暫停。
- 重新整理後要確認剛才的單據是否已存在。
- 還原備份前應先匯出目前資料。
- 借出、轉出貨、歸還、應收、獎金都可透過單據編號追查。

## 驗證標準

自動驗證：

- 主規格必須連到本規格。
- 專案必須存在本規格檔案。
- 後續若加入 UI，`index.html` 必須有 `data-tab="learning"` 或等價入口。
- 教學文字 key 必須納入文字基準線檢查。

人肉驗證：

1. 從右上角可進入教學專區。
2. 左側或頂部可看到章節目錄。
3. 可搜尋同步、備份、借出、應收、獎金等關鍵字。
4. 每章有上一章 / 下一章。
5. 至少一章有操作練習。
6. 情境題能讓新人判斷「借出歸還不可直接回可售庫存」。
7. 教學可引導同事用範例資料查到 `LOAN`、`LRTN`、`SO`、`PO`。

## 非第一版範圍

- 影片教學。
- 線上帳號進度同步。
- 憑證或考試。
- 外部 LMS 整合。
- AI 對話式教學。
