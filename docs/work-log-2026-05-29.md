# StockFlow 工作日誌：2026-05-29

今天主要完成 StockFlow 進銷存系統從 `v1.14.2` 到 `v1.15.2` 的整理與功能推進。

## 完成版本

### v1.14.2：抽出模型與工具

- 新增 `inventoryUtils.js`。
- 新增 `inventoryModels.js`。
- 先把工具函式、模型正規化與部分 copy helper 從 `inventoryStore.js` 拆出。
- 維持 store 對外 API 不變。

### v1.14.3：抽出報表計算

- 新增 `inventoryReports.js`。
- 抽出庫存報表、儀表板摘要、毛利排行、倉庫摘要、商品跨倉分布、庫存異動與庫存匯出。
- `inventoryStore.js` 改用 `reportState()` 委派報表計算。

### v1.14.4：抽出儲存、備份、還原

- 新增 `inventoryStorage.js`。
- 抽出 localStorage key、資料版本、儲存 envelope、migration、備份驗證與備份摘要。
- 修正一個 migration 邊界：有 `state` 外殼但沒有 `schemaVersion` 的備份，現在會正確讀取 `state`。

### v1.14.5：抽出畫面渲染

- 新增 `inventoryRenderers.js`。
- 先把報表中心渲染從 `app.js` 抽出。
- 建立後續繼續搬 UI renderer 的模式。

### v1.14.6：CSS 分區整理

- 保留單一 `styles.css`。
- 加入 Base、Layout、Controls、Reports、Panels and forms、Tables、Lists and cards、Responsive 等區塊註解。
- 沒有大改視覺，只整理樣式地圖。

### v1.14.7：錯誤訊息與防護整理

- 新增 `inventoryMessages.js`。
- 集中商品、往來對象、主檔、採購、銷售、盤點與作廢進貨的常見錯誤訊息。
- `app.js` 改用 `StockFlowMessages.message()` 與 `StockFlowMessages.transactionError()`。

### v1.14.8：收束

- `v1.14.x` 深度整理分支收束。
- 模組分工穩定為：utils、models、reports、store、storage、renderers、messages、app。
- 版本與快取參數升到 `1.14.8`。

### v1.15.0：倉庫調撥核心版

- 新增 `transfers` 資料集合。
- 資料版本升到 `schemaVersion = 6`。
- `inventoryModels.js` 新增調撥模型正規化與 copy helper。
- `inventoryStore.js` 新增 `addTransferOrder()` 與 `listTransfers()`。
- 調撥會檢查來源倉庫庫存。
- 來源倉與目的倉不可相同。
- `inventoryReports.js` 的庫存計算納入調撥入庫與調撥出庫。
- 庫存異動明細會顯示調撥進、調撥出兩筆。

### v1.15.1：調撥單 UI 與列表

- 新增「倉庫調撥」頁籤。
- 新增調撥表單：來源倉庫、目的倉庫、兩筆商品明細、日期、備註。
- 新增調撥列表。
- 新增調撥查詢與月份篩選。
- `app.js` 串接調撥核心 API。

### v1.15.2：調撥報表

- 新增 `warehouseTransferSummary()`。
- 報表中心新增「倉庫調撥流向」。
- 可依報表月份查看各倉庫調入、調出、淨流量與調撥筆數。
- 更新測試，確認調撥流向摘要正確。
